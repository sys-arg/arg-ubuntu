# PR #27 main 브랜치 C 전용 제출 검사 추가

## 관련 Issue

- [#26 main PR에 C 전용 제출 검사 추가](https://github.com/sys-arg/arg-ubuntu/issues/26)

## 구현한 기능

### main PR 제출 검사

- 동작 — `main` 대상 PR의 병합 후보 전체에서 허용 파일 형식과 Makefile의 Python 참조를 검증한다.
- 사용 기술 — GitHub Actions의 PR 브랜치 필터와 읽기 전용 체크아웃, Git 추적 트리, Bash, awk를 사용한다.
- 핵심 코드 — [`.github/workflows/main-c-only.yml`](../.github/workflows/main-c-only.yml#L22)의 파일·내용 검증 단계.

## 주요 변경 사항

- [`.github/workflows/main-c-only.yml`](../.github/workflows/main-c-only.yml)에 `C-only submission` 작업을 정의한다.

## 검증 결과

- 환경 — macOS, 임시 Git 저장소와 Bash.
- 실행한 검증 — YAML 트리와 `bash -n`을 확인했다. 정상 C·문서·Makefile, 금지 확장자와 확장자 없는 파일, Makefile의 Python 호출, `.mk`의 Python 명령, `.py` 참조, C 확장자를 쓴 심볼릭 링크, 미추적 파일 케이스가 기대 종료 코드로 동작했다.
- 미검증 — 실제 GitHub Actions의 `main` 대상 PR 첫 실행과 필수 검사 연결은 릴리스 PR에서 확인한다.
