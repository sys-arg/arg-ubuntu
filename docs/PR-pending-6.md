# 이슈 #6 Codex 작업 및 문서 작성 규약 추가

## 관련 Issue

- [이슈 #6](https://github.com/sys-arg/arg-ubuntu/issues/6)

## 구현한 기능

### Codex 작업 규칙

- 동작 — 작업 전 Issue와 필수 선행 Issue를 확인하고, PR 전 검증과 변경 기록 절차를 안내한다.
- 사용 기술 — Markdown 상대 링크로 `CONTRIBUTING.md`와 `DOCS.md`를 참조한다.
- 핵심 문서 — `AGENTS.md`의 작업 기준, 협업과 변경 범위, PR 전 2차 검증과 변경 기록 항목

### Markdown 문서 작성 규약

- 동작 — `docs/`의 파일명과 서식, PR 변경 기록 작성 절차와 양식을 정의한다.
- 사용 기술 — Markdown 코드 블록으로 변경 기록 양식을 보여준다. 양식에는 기능별 사용 기술과 역할, 핵심 코드 경로와 함수명 또는 줄 번호가 포함된다.
- 핵심 문서 — `DOCS.md`의 파일명과 서식, PR 변경 기록 항목

## 주요 변경 사항

- [AGENTS.md](../AGENTS.md)에 팀 공통 Codex 작업 규칙을 추가했다.
- [DOCS.md](../DOCS.md)에 팀 공통 문서 작성 규약을 추가했다.

## 검증 결과

- macOS 작업 트리에서 저장소 루트를 기준으로 최신 Issue 본문과 변경 범위를 대조했다.
- Python 3으로 첨부본과 일치 여부, 상대 링크의 대상 파일, 줄 끝 공백을 확인했다.
- 제품 코드 변경이 없는 문서 작업이므로 Ubuntu 빌드와 런타임 테스트는 실행하지 않았다.
